Hearth & Ledger: a working household budget site — a November overview with money left to spend and a spending donut, an editable monthly plan per category, a transaction ledger you can add to, filter and delete from, bills and savings goals with landing dates, and an insights page with a 50/30/20 check and six-month chart. Vanilla JS modules, no framework, books kept in local storage.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts — then open out/app/index.html in a browser (or serve app/ statically)
```
